# Shortsmaker

편집한 가로 롱폼을 주제별 쇼츠로 만들고 Instagram·YouTube에 예약하는 Mac 로컬 앱.

## 실행

`시작.command`를 더블클릭하면 `http://127.0.0.1:5099`가 열립니다. 터미널을 닫으면 서버가 종료됩니다.

필요 환경: Python 3.14, FFmpeg/ffprobe, Codex CLI의 ChatGPT 구독 로그인. 첫 실행 시 Python 패키지와 음성 인식 모델을 다운로드합니다. GmarketSansBold가 설치되어 있으면 사용하며 없으면 Mac 기본 한글 폰트로 표시합니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

## 작업 흐름

1. 편집한 가로 원본을 불러오고 **① AI 자동 준비**를 누릅니다. 내용 분석·주제 분할 → 후킹10개 → 설명 그림·글 등장 구간 찾기을 순서대로 진행합니다. 전사는 분석용이며 새 자막은 넣지 않습니다.
2. 준비 완료 후 쇼츠 구간과 문구를 검토합니다. 필요하면 나누기·합치기·제외·문구/강조 수정, 드래그·정렬·확대율 조정을 합니다. 기본은150%·중앙 고정이고 설명 자료 구간에는 AI 추천 위치를 자동 적용합니다.
   **화면 구도**에는 설명 자료의 원본 썸네일·등장 구간·추천 정렬/배율이 나옵니다. 추천 위치는 미리 적용되어 있습니다. 이상하면 **이 구간 위치 조정**으로 이동한 뒤 드래그하거나 좌/중/우 버튼을 누르세요. 재분석해도 직접 조정한 위치는 유지합니다. 선택한 설명 구간에만 적용되며 앞뒤는 기본 구도로 돌아옵니다. **쇼츠 전체 위치 편집으로**으로 전체 기본값을 바꿀 수 있습니다. 경계는 약2초 간격 분석 기준이므로 미리보기로 확인하세요.
3. **② 검토 완료 · 예약 달력**을 누릅니다. 기본은 내일부터 매일 한국 시간 낮12시에 한 편씩, 같은 쇼츠를 인스타·유튜브에 함께 발행합니다. 기존 예약이 있는 날은 건너뜁니다.
4. 달력에서 날짜별 문구를 확인합니다. 필요하면 시작일만 바꿉니다. 채널과 YouTube 공개 범위는 접힌 설정에서 변경할 수 있으며 마지막 선택을 기억합니다.
5. **이 달력으로 확정 · 인코딩 및 예약**을 누르면 포함된 쇼츠의 문구·구도를 일괄 승인하고 인코딩 → R2 업로드 → Buffer 예약을 자동 진행합니다. 달력을 여는 것만으로 승인·예약하지 않습니다.

개별 문구 확정 버튼을 모두 누를 필요는 없습니다. 최종 달력 확정이 현재 선택된 문구·구도의 일괄 승인입니다. 개별 단계만 다시 실행하거나 영상만 인코딩하려면 **개별 단계 다시 실행**을 펼칩니다.

완료된 준비 단계는 저장되며 실패/중단 후 재시도하면 이어서 처리합니다. 중단 후 편집이 바뀌었다면 개별 단계 또는 자동 준비를 새로 실행하세요. 인코딩 실패 시 예약은 시작하지 않고, 이미 예약된 항목은 중복 생성하지 않습니다. 확정 이후 날짜 충돌이나 시각 경과가 생기면 자동으로 날짜를 바꾸지 않고 다시 확인하도록 멈춥니다.

기본 AI는 `gpt-6-astra` / `medium`, 설정에서 변경할 수 있습니다. 음성 인식은 로컬 faster-whisper medium입니다. AI는 전사와 대표 프레임을 사용하므로 구독 사용량을 소비합니다.

## 파일과 복구

- 원본 영상은 수정하지 않습니다. 프로젝트·전사·AI 응답·완성본은 `data/projects/`에 저장됩니다. 앱의 폴더 열기는 프로젝트별 `완성 영상/` 폴더를 엽니다.
- 각 단계 완료 내용을 저장하고 앱 재시작 후 중단 작업은 재시도할 수 있습니다.
- 편집 변경 시 이전 출력은 남겨두고 새 출력만 만듭니다. 현재 내용과 다른 출력은 예약에 사용하지 않습니다.
- R2의 예약용 복사본은 선택한 모든 채널에서 발행 성공한 뒤 14일 후 정리합니다. 앱 시작 및 실행 중 매시간 확인하며, 앱이 꺼져 있으면 다음 실행 때 처리합니다.
- 예약/오류/상태 불명 영상은 자동 삭제하지 않습니다. Mac 원본·완성본은 자동 삭제하지 않습니다.
- 예약 응답이 유실되면 중복 방지를 위해 자동 재생성을 멈춥니다. Buffer에서 확인한 게시물 ID를 연결한 후 처리합니다.
- `.env.local`에 `.env.example`의 Buffer/R2 설정을 입력합니다. 비밀값과 영상은 Git에 올리지 않습니다.

## 개발 검증

```sh
.venv/bin/python -m pytest -q
node --check static/app.js
```

초기 검증은 `docs/verification/initial-version.md`, 자동 진행·달력 검증은 `docs/verification/automatic-calendar.md`에 기록합니다. 개인 실사용 베타 구현 및 두 원본16개 쇼츠 검증을 완료했습니다. 실제 플랫폼 발행 시험은 하지 않았습니다.
