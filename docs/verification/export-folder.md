# 저장 폴더 필수 설정 검증 (2026-09-10)

- 프로젝트별 저장 폴더 선택/변경과 현재 경로 표시. 인코딩 및 예약 달력 진입시 미설정이면 Mac choose folder를 호출하고 취소시 중단.
- 서버 인코딩 요청/실행과 달력 확정/재개에서도 경로 존재/쓰기 가능 여부 확인. 기본 폴더로 자동 저장하지 않음.
- 테스트40개 통과. 새 테스트:미설정 차단,선택창 취소/성공 응답과 영구 저장,지정 디렉터리로 파일 복사,경로 이동후 차단,저장 위치 없는 달력 승인 차단. 폴더 선택 응답/인코더는 테스트에서 대체했고 실제 임시 파일 복사·내용 일치를 확인. 기존FFmpeg 출력 회귀 포함.
- 실제 브라우저에 필수 설정 버튼/미설정 안내 표시,JS오류 없음. 사용자의 저장 위치는 임의 지정하지 않았으며 최초 선택 대기. 기존 파일 이동/삭제와 원격 예약 없음.
- 새 경로는 최종 완성본 위치이며 내부 렌더 캐시는 data/projects에 유지. 다른 Mac에서 경로가 없으면 재설정 필요.

## 선택 시점 정정
- 별도설정버튼제거. 인코딩만/달력최종실행시매번선택,달력열때는선택안함.
- 브라우저에서 이전경로가있는상태로인코딩버튼클릭→폴더선택API호출1회,취소응답시인코딩요청없음확인. 선택API는시험중취소응답으로대체,사용자설정/실제인코딩변경없음. JS문법/오류검사통과.
