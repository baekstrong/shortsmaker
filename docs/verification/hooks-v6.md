# 후킹 v6 검증 (2026-10-21)

기준: `docs/reviews/hook-benchmark-2026-10-21.md`

## 변경
- 생성 입력에서 쇼츠 제목과 현재 문구를 뺐다. v5는 제목을 질문형으로 바꾸는 데 그치는 경우가 많았다.
- 규칙을 금지 위주에서 채널 성과 기반 각도 중심으로 바꿨다. 각도는 우선순위 순으로 통념 뒤집기, 작거나 대비되는 숫자, 답 가리기, 정체성·공통점, 실제 실패담, 흔한 고민 묻기다. 성과가 좋았던 예시와 약했던 예시도 넣었다. 후보 10개에는 각도를 3가지 이상 섞되, 근거 없는 각도는 쓰지 않는다.
- 검수 순위에서 명확성을 다시 우대하지 않는다. 이해와 근거는 통과 기준으로만 보고, 순위는 반전 정도, 자기 관련성, 구체성 순으로 정한다. `compelling_question`은 교과서형 질문과 좁은 대상을 탈락시킨다.
- 글자 수(15~20자, 두 줄), 스키마, 사실 근거 규칙은 그대로다. `HOOK_VERSION = 6`.

## 실제 비교
- 대상: 기존 프로젝트 2개(장요근 1ecfdd9e, 운동 멈춤 기준 e284abd2)의 이미 게시된 쇼츠 6개.
- 모델 차이를 없애려고 v5와 v6 모두 `claude-opus-5-5` / `medium`으로 새로 생성했다. 각 칸은 검수 1순위 문구다.
- 저장된 v5 결과는 Astra로 만든 것이고, 게시 문구는 사용자가 고친 최종본이다. 조회수는 2026-10-21 기준이다.

| 쇼츠 | 게시 문구 (조회수) | v5 · Opus 1순위 | v6 · Opus 1순위 |
|---|---|---|---|
| 스쿼트·달리기 공통 고관절 | 스쿼트와 달리기에서 / 장요근이 핵심인 이유 (4.3만) | 체력 키울 때 / 종목보다 먼저 볼 관절 | 운동 종목만 잘 고르면 / 체력 늘까요? |
| 힙힌지 옆모습 촬영 | 데드리프트가 어렵다면 정강이를 보세요 (2.3천) | 엉덩이 뺄 때 정강이가 기울어지나요? | 엉덩이 빼라는데 / 무릎만 굽혀진다면 |
| 데드리프트 허리 젖힘 | 데드리프트할 때 / 허리 뻐근한 이유 (1.7천) | 데드리프트 마무리에 / 허리가 젖혀진다면 | 엉덩이 조여도 / 허리만 뻐근하다면 |
| 체력의 의미 | 저질체력이 알아야 하는 / 체력의 진짜 의미 (2.6천) | 오후면 지치는 몸, / 뭘 키워야 할까 | 체력 키우려고 / 녹초 될 필요 없어요 |
| 세트 종료 기준 | 근력 운동, / 몇 회까지 해야할까? (3만) | 근력 운동 한 세트, / 언제 끝낼까? | 마지막 한 개 더 / 짜낼 필요 없습니다 |
| 달리기 속도 저하 | 처음 달리던 속도를 꼭 유지해야 할까? (3.4천) | 달리다 느려지면 그만 뛰어야 할까? | 달리다 느려졌다고 / 멈추지 마세요 |

v6의 2·3순위:
- 고관절: 좋은 운동 골라도 / 놓치는 한 가지 · 스쿼트·달리기 / 공통점은 한 곳입니다
- 힙힌지: 무릎부터 나가는 스쿼트 / 범인은 따로? · 앉는 건 중력이 해준다? / 반만 맞아요
- 데드리프트: 데드리프트하면 / 허리부터 뻐근하다면? (통과 2개뿐)
- 체력 의미: 지칠 때까지 해야 / 체력이 는다고요? · 끝까지 버티는 게 / 체력이 아닙니다
- 세트 종료: 세트를 끝낼 신호는 / 횟수가 아닙니다 · 끝까지 버텨야 / 세트가 끝날까요?
- 달리기: 느려지는 게 맞는 / 달리기도 있습니다 · 같은 속도로 끝까지 / 뛰어야 할까요?

## 관찰
- v6 1순위 6개 중 4개가 벤치마크 상위 패턴인 "열심히 하는 행동 뒤집기"다(녹초 될 필요 없어요, 짜낼 필요 없습니다, 멈추지 마세요, 엉덩이 조여도). v5는 6개 모두 "언제/무엇/왜"를 묻는 질문형이었다.
- v6의 `viewer_expectation`(시청자의 통념)과 `new_insight`(영상의 반전)가 문구에 직접 반영됐다. 예: 통념 "마지막 한 개를 더 짜내야 제대로 한 것" → 문구 "마지막 한 개 더 짜낼 필요 없습니다".
- 검수가 더 엄격해져 통과 수가 줄었다(v5 7~8개 → v6 2~8개, 데드리프트는 2개). 통과가 0개면 재생성 후 오류가 나는 기존 동작은 그대로다.
- 주의할 후보: 힙힌지 클립의 "무릎부터 나가는 스쿼트"처럼 데드리프트·힙힌지 내용을 스쿼트로 넓힌 문구가 2순위로 통과했다. 사람이 최종 선택할 때 확인이 필요하다.
- 게시 후 4.3만 회가 나온 "장요근이 핵심인 이유"보다 v6 문구가 나은지는 데이터로 알 수 없다. 이 비교는 문구 유형의 변화를 보여줄 뿐 조회수를 예측하지 않는다. 실제 효과는 v6 문구로 게시한 쇼츠의 하루 평균 조회수로 확인해야 한다.

## 검증
- `pytest` 254개 통과. 생성 프롬프트에 쇼츠 제목이 들어가지 않는지 검사를 추가했고, 저장되는 `hook_version` 검사는 `ai.HOOK_VERSION`을 따르게 바꿨다.
- 비교 실행은 프로젝트 데이터에 저장하지 않았다(별도 캐시 폴더, `fresh=True`).
