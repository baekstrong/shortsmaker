# 원본 컷 기준 화면 구도 검증 — 2026-10-16

## 문제와 변경

정렬 전환이 실제 장면보다 약0.1초 늦고, 사용자가 컷별로 정확히 고치기 어려웠다. 기존 분석은1초 간격으로 컷을 찾고 약2초 간격 화면의 중간값으로 적용 시간을 추정했다. 미리보기 구도 갱신도 영상의 `timeupdate` 이벤트에 의존했다.

- 원본을 연속 디코딩해 새 장면 첫 프레임의 실제 재생 시각(PTS)을 저장한다. 일반 움직임과 자료 전환을 주변 프레임·화면 영역별 변화로 구분하며 최소2초 제한을 제거했다. 가변 프레임률도 평균FPS로 시간을 환산하지 않는다.
- AI는 검출한 컷마다 대표 화면을 보고 제안한다. 제안 시작·끝은 컷 경계이며, 이웃 컷과 합치지 않는다. 수동 수정 경계와 기존 적용 구도는 재분석해도 보존한다.
- 썸네일 타임라인·확대·컷 선택·한 프레임 이동·좌우 정렬·확대/드래그·경계 이동/추가/합치기를 제공한다. 모든 변경은 구도 범위에 한정하며 영상·음성 삭제와 구분한다.
- 미리보기는 표시되는 프레임의 `mediaTime`에 맞춰 갱신한다. 출력은 구도 구간 끝을 자른 뒤30fps로 변환하여 다음 장면 프레임이 이전 구도로 남는 현상을 방지한다. 렌더 캐시 버전은8이다.

## 사용과 한계

기존 앱 화면을 새로고침한 뒤 **원본 컷 찾기**로 타임라인을 만든다. 기존 AI 제안을 새 방식으로 다시 받으려면 **설명 화면 찾기**를 실행한다. 원하는 컷을 선택한 뒤 정렬/확대율을 바꾸고, 시작·끝의±1프레임 버튼이나 현재 프레임 맞춤으로 보정한다.

검출은 시각적 휴리스틱이다. 점진적 전환이나 작은 자료 변화에서 경계를 놓치거나 과하게 나눌 수 있어 수동 경계 추가·합치기를 제공한다. 출력은 기존30fps이므로60fps 원본의 경계가 출력 한 프레임 간격으로 양자화될 수 있다. 전체 장면의 수동 정답 라벨 비교나 전편 연속 시청 검증은 수행하지 않았다. 예약·발행은 실행하지 않았다.
