# 후킹 생성·독립 검수 검증 (2026-10-02)

## 변경과 판단 기준
- 15자에 맞추느라 대상과 궁금증의 내용을 지우는 문제, 작성자가 자기 후보를 정당화하는 문제를 해결한다. 시청자 문제·예상과 영상의 새 단서·근거를 먼저 분석해 자유 후보10개를 작성한다. 같은 단서를 자연스러운 여러 표현으로 전달할 수 있고, 서로 다른 사실이나 유형10개를 강제하지 않는다.
- 별도 호출은 후보 원문과 실제 남은 내용·첫 화면만 받아10개를 검수한다. 생성 분석·접근 의도·추천 이유는 전달하지 않는다. 통과 후보를 좋은 순서대로 최대10개 저장하고 첫 후보를 추천한다.
- 첫 실제 운동 편 초안은18/20개가 레그컬 중심으로 원래 스쿼트 무릎 문제와 교정 목적이 사라졌다. 독립 편집 검토에서 이 약점을 확인하고, 원본 주제명과 흐름 요약을 사용 목적의 보조 맥락으로 추가했다. 생성자·검수자 모두 원래 대상이 왜 이 시범을 봐야 하는지 확인하게 했다. 다른 쇼츠의 설명을 이 쇼츠의 답으로 약속하는 것은 금지한다.
- 의미 판단은 문구 단독 이해·구체적인 시청 이유·영상이 제공하는 답·첫 발언/화면 연결·자연스러운 표현·동작 오해를 확인한다. 질문형 비율·고정 문구·운동명 반복은 강제하지 않는다.
- 코드 검증은 공백·문장부호·줄바꿈 포함15자, 최대 두 줄, 중복 없음, 강조 포함, 전 후보 검수와 통과 여부, 통과 후보 전체 선정 및 순위를 확인한다. 오류/10개 미달 시 약한 후보만 한 번 보완하고 재검수한다. 통과 후보의 원문·강조·표현 의도는 로컬에서 강제 보존한다. 이전 전체 분석과 긴 검수 결과 대신 후보별 짧은 보완 지시만 전달한다. 보완 후10개 미달이어도 통과 후보가 있으면 그 문구만 제안한다.0개 또는 형식 오류면 기존 상태를 보존한다.
- 첫3/8초 전사는 삭제를 건넌 편집 후 시간으로 제한한다. 화면4개도 편집 후0.2/1.5/3/6초를 원본으로 매핑한다. 크롭 전 원본 화면이라는 한계는 프롬프트에 명시한다.
- 다중 쇼츠 검수는 전부 완료한 뒤 리비전 확인과 한 번의 되돌리기 이력으로 저장한다. 사용자 동시 수정·실패·취소 때 부분 저장하지 않는다. 일반 재생성은 확정 문구를 보존하고 명시적 교체만 확인 대기로 변경한다.

## 실제 두 쇼츠 생성·미리보기
- 현재 두 쇼츠의 선택 문구와 검수 통과 후보를 앱에 저장했다(revision53→55, 이번 작업의 되돌리기1회로 원래 두 문구 복원). 원인 편은 `무릎 안 벌어져?\n발에 단서`, 운동 편은 `무릎 벌리려면\n붙이는 운동?`다. 각각 줄바꿈 포함15자이며 두 번째 줄 핵심 구절을 노란색으로 강조했다. 최종10후보의 실제 모델 생성과 별도 독립 검수 모두 완료했으며, 원인 편0·4번/운동 편7번만 통과했다. 별도 편집 검토도 같은 최우선 후보를 추천했다. 초기 운동 문구 ‘기구 없이’는 구체적인 시청 단서가 부족한 미완성 표현으로 탈락해, 목적과 동작의 의외성을 연결하는7번으로 개선했다. 앱 후보 목록도 통과한 원인2개/운동1개로 교체해 탈락한 추천을 남기지 않았다.
- 앱에서 두 줄·강조·1080×1920 후킹 이미지 로드·미리보기 오류 없음·가로 넘침 없음을 확인했다. 기존 출력/예약 관련16개 파일의 SHA256와 크기가 모두 동일하다.15개 파일의 수정 시각도 동일하며 예약 저장소1개는 서버 시작의 기존 초기화 로직이 같은 내용을 다시 저장해 수정 시각만 갱신했다. 검증 사본과 스크린샷은 커밋하지 않는 `data/verification/hooks-v4-20261002/`에 있다.
- 초기20후보 방식은 독립 검수에서 원인5개/운동3개만 통과했고, 원본 목적을 보완한 재작성에서20분 호출 제한에 도달했다. 후보 수를10개로 줄이고 통과 후보를 보존하며 보완 지시를 간결하게 수정했다. 최종10후보 방식에서도 통과안은2개/1개였다. 무조건10개를 요구하면 결과를 제공하지 못하는 문제가 있어,1회 보완 후에도 개수가 적으면 통과한 후보만 제안하도록 수정했다. 실제 격리 실행은 초안2개와 독립 검수2개 응답을 받은 뒤 전체 검증 대기12분 제한으로 중단되어 자동 보완·재검수까지 완료하지 않았다. 이 사본은 부분 저장되지 않았고, 현재 앱 반영은 완료한 실제 초안·독립 검수 응답에서 편집자가 선택해 수행한 것이다. 자동 보완·부분 통과 저장·0개 실패 동작은 단위 테스트로 검증한다.

## 범위와 한계
- 이번 작업에서 실제 영상 인코딩·예약 변경·새 발행은 하지 않는다. 기존 완성 영상과 예약은 보존하며, 새 문구가 들어간 영상 파일은 별도로 인코딩해야 한다.
- 문구의 의미 판단과 추천은 AI 및 편집 검토 결과다. 실제 조회수·시청 유지 효과는 측정하지 않았다.
