## 변경과 기준

- 기존에는 소재의 시작·끝만 저장하고 내부 발언을 제거할 수 없었다. 자동 준비에 내용 편집 단계를 추가하고, 원본 타임코드로 삭제 구간과 이유를 저장한다.
- 문장·단어 전사와 원본 0.5초 간격 화면을 함께 보고 반복 설명, 예고·전환·홍보, 촬영 준비·카메라 조정·테스트 화면을 삭제한다. 운동 이름·필수 조건·주의사항·필요한 시범과 자연스러운 연결은 보존한다. 목표 삭제 비율은 없다.
- 후킹은 삭제 후 남은 발언을 기준으로 생성한다. 기존 프로젝트를 다시 편집할 때 이미 선택한 문구와 직접 조정한 구도는 유지한다.
- 미리보기와 출력에서 같은 삭제 구간을 제외한다. 출력은 남은 화면만 연결하고, 원본 음성을 삭제·연결한 후 AAC로 한 번 인코딩한다. 삭제 구간에 걸친 설명 구도는 남은 원본 시간에만 적용한다.
- 앱에서 삭제 이유 확인, 개별 복원, 직접 삭제, 되돌리기를 지원한다. 길이 제한과 예약 검증은 실제 편집 후 길이를 사용하며, 컷 변경 시 기존 출력·달력의 일치 검사를 무효화한다.
