- 로컬 faster-whisper 전사, Codex 구독 구조화 AI 분할·후킹10개, 응답 캐시·검증.
- 장면 전환/시간별 대표 프레임과 AI 중요 영역 추정 → 장면별 고정 구도. 기존 자막·판서·손동작을 포함하도록 지시하고 불확실 시 확인 표시. 움직임 추적 정밀화는 검증 후 보정 예정.
- 1080×1920 공통 배치/후킹 PNG, 영상 H264/AAC 출력·현재 설정과 출력 일치 키.
