상세 수치: [final-output-audit.json](final-output-audit.json). 검사 스크립트는 `python -m scripts.audit_outputs`이며 검증용 문구 확정 상태에서 실행한다. 샘플은 검사 후 사용자 문구 확인 대기로 돌려놓았고 출력 파일은 보존했다. 테스트의 임시 추천 선택은 사용자 승인을 대신하지 않는다.

## 화면·상태·복구

- 브라우저 실제 파일 불러오기, 시작/끝·2줄 문구·강조·확정 저장, 수동 확대율, 재생/탐색, 미리보기와 출력 프레임 확인.
- 분할9→10→되돌리기9, 합치기9→8→되돌리기9, 제외→되돌리기 실제 조작 확인.
- 모델 선택 Astra→Sol 저장→Astra 복원, medium 기본 유지. 대체 모델 호출은 시험하지 않았으며 기본 Astra 구독 호출은 실제 분할·후킹·이미지 분석으로 검증했다.
- 작업 완료 Web Audio 발음 시작1회와 완료ID 저장 확인. 새로고침 시 이전 완료ID를 재생하지 않는 구조.
- 앱 재시작 후 프로젝트/편집/출력 유지, 중복 서버 실행 거절.
- `pytest`20개 통과: 원자 저장·편집 충돌·되돌리기, 렌더 키·기하·강조/문장부호, 프로세스 취소/종료/잔여 프로세스 복구, 원격 보관·예약 중복/부분실패/불명확 응답/삭제 재시도, 로컬 요청 보호, 실제 FFmpeg 다중 장면 오디오 회귀 검사.
- JavaScript 문법 검사·Python 컴파일 검사 통과, 브라우저 JS 오류 없음.

## 예약·보관

- 앱 생성 영상1개를 R2에 업로드하고 Instagram/YouTube에7일 후 예약. YouTube는 시험용 비공개.
- 두 채널 `scheduled` 별도 조회 후 즉시 삭제. 두 게시물 `NOT_FOUND` 및 공개 영상HTTP404 독립 재확인.
- 실제 발행하지 않았으며 활성 테스트 예약/원격 영상은 남기지 않았다. [예약 검증 결과](app-reservation-test.json).
- 모든 선택 채널의 `sent`+`sentAt` 확인 후14일 정리. 예정/실패/불명확/누락 채널은 보존. 시간 조건은 테스트 시계로 검증했으며 실제14일을 기다린 시험은 아니다.
- 앱 시작 및 매시간 확인, Mac 원본·완성 영상은 자동 삭제하지 않는다.

## 수정한 주요 문제

- 빠른 연속 입력에서 앞선 저장 응답이 다음 입력을 덮음 → 저장 순서 보장·입력 중 값 보존·오래된 폴링 응답 배제 후 재검증.
- 장면별 AAC를 합칠 때 음성 지연 누적 → 영상만 합치고 원본 구간 오디오를 마지막에 한 번 인코딩. 실제147초/11개 장면 및 전체16개 출력 대조 통과.
- 개별 글자 렌더에서 쉼표가 위로 올라감 → 공통 기준선 정렬 및 이미지 회귀 검사.

## 초기 버전의 범위

- AI 구도는 대표 프레임과1초 간격 OCR을 이용한다. 장면 사이의 빠른 움직임이나 인식 누락을 완벽하게 보장하지 않으므로 미리보기 확인·수동 보정을 제공한다. 폭이 넓은 자막/판서는150%보다 축소될 수 있다.
- 구독 사용량을 소비한다. 첫 음성 인식은 모델 다운로드가 필요하다.
- 현재 R2 개발용 공개 주소를 사용한다. 실제 플랫폼 발행 성공은 사용자 요청에 따라 시험하지 않았다.
- 사용자 확인 없는 완전 자동 모드는 후속 범위이며 초기 버전에 포함하지 않는다.
