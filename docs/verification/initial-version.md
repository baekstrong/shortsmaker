# 초기 버전 구현·검증 기록

2026-09-10. 목표: 두 제공 원본에서 입력→AI 분할/수정→후킹10개/확정→자동구도/미리보기→인코딩→예약까지 동작하는 개인 실사용 베타.

## 구현
- Flask 로컬 웹 UI, Mac 실행 명령, 프로젝트 원자 저장·revision 충돌 감지·편집 되돌리기.
- 단일 무거운 작업 큐, subprocess 중단/시간 제한, 앱 재시작 시 중단 표시·재시도, 단계별 음향 알림.
- 로컬 faster-whisper 전사, Codex 구독 구조화 AI 분할·후킹10개, 응답 캐시·검증.
- 장면 전환/시간별 대표 프레임과 AI 중요 영역 추정 → 장면별 고정 구도. 기존 자막·판서·손동작을 포함하도록 지시하고 불확실 시 확인 표시. 움직임 추적 정밀화는 검증 후 보정 예정.
- 1080×1920 공통 배치/후킹 PNG, 영상 H264/AAC 출력·현재 설정과 출력 일치 키.
- R2 공개 URL 업로드, Buffer 두 채널 예약·조회·삭제, 예약 전 기록으로 중복 재시도 차단, 전 채널 발행+14일 정리.

## 확인한 증거
- `pytest`: 저장/되돌리기·충돌, 레이아웃·강조, 구간별 배치, 프로세스 취소·재시작, 보관 조건, 예약 중복·응답 유실·부분 실패·삭제 확인 등 11개 통과.
- 브라우저 홈 화면·실제 파일 경로로 프로젝트 생성·편집 화면 렌더 확인. 콘솔 JS 오류 없음.
- 운동 밀당 10:39 전체 한국어 전사 성공. AI는 48~147초 구간7개 제안, 모두 180초 이하.

## 아직 검증 중
- 후킹 전체 생성, 두 원본 자동 구도 품질, 실제 인코딩 결과 및 미리보기 비교.
- 수업 원본 전체 흐름, UI 편집/알림/복구 및 신규 앱 경유 예약 생성·조회·즉시삭제.
- 초기 버전 완성을 뜻하는 문서가 아니다. 실제 발행 성공은 테스트 범위에서 제외한다.
