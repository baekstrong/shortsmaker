# 쇼츠 후킹 벤치마크 (2026-10-21)

후킹 v6 설계 전에 백관장 채널(@easystrength101, 쇼츠 433개)과 참고 채널 어썸블리스(@어썸블리스, 쇼츠 461개)의 조회수 상·하위 쇼츠를 비교했다.

## 수집 방법과 한계
- 2026-10-21 YouTube 채널 쇼츠 탭에서 공개된 조회수(반올림 표시)와 제목을 전체 수집했다.
- 최신성 반영: 최신순 목록에서 12개 간격으로 실제 게시일을 확인하고, 그 사이는 순서로 보간했다. 지표는 `하루 평균 조회수 = 조회수 ÷ 게시 후 일수`이며, 최근 1년(2025-10-21 이후)·게시 14일 이상만 비교했다.
- 화면 문구는 각 쇼츠의 첫 프레임(`i.ytimg.com/vi/<id>/frame0.jpg`)으로 확인했다. 1초 이후에 나타나는 문구와 첫 발언 음성은 확인하지 못했다.
- 조회수에는 주제·화면 형식·게시 시기·알고리즘이 함께 작용한다. 아래 내용은 상관 관찰이며 후킹 문구만의 효과로 단정하지 않는다.
- 대량 메타데이터 조회는 YouTube 봇 확인에 걸려 중단했고, 우회하지 않고 브라우저의 공개 채널 화면 데이터로 대신했다.

- 누적 상위는 세로 전체 화면으로 헬스장·야외에서 동작을 직접 보여주고, 상단에 짧은 문구(대부분 2~3어절과 숫자)를 올렸다.
- 2026년 쇼츠는 앉아서 말하는 롱폼 장면을 상하 검은 띠 안에 넣은 형식이며 하루 평균이 수십~수백 회로 떨어졌다. 같은 채널 안에서는 문구보다 형식 차이가 더 크게 보인다.

### 같은 형식(최근 1년) 안에서 상위 vs 하위
| 상위 (하루 평균) | 하위 (하루 평균) |
|---|---|
| 체력 운동은 2개면 충분합니다 (551) | 케틀벨스윙 하다가 다치는 이유 3가지 (7) |
| 매번 무게 올리면 오히려 안 늡니다 (462) | 듀얼 모니터 쓰면 허리 아픈 이유 (7) |
| 러닝할 때 숨이 턱까지 차야 운동이 잘된 걸까? (344) | 아무리 좋은 의자 써도 허리 아픈 이유 (6) |
| 진짜 체력은 이 운동에서 나옵니다 (328) | 케틀벨 클린 3단계 어퍼컷 (6) |
| 열심히 운동할수록 망하는 이유 (291) | 모니터 멀리두면 허리 아픈 이유 (4) |
| 근력과 유산소 꼭 따로 해야 할까요? (273) | 매일 할 수 있는 근력 운동량 구하는 법 (3) |
| 시간 없으면 근력운동부터 해야 하는 이유 (257) | |
| 케틀벨 24kg 1년간 방치한 이유 (221) | |
| 힘 키우려면 10개 대신 6개? 3분의 2 법칙 (221) | |
| 피곤한 날 운동하다가 반년 쉬었습니다 (197) | |
| 숨넘어가게 안 해도 체력은 늡니다 (187) | |

상위 공통점:
1. **시청자가 열심히 하고 있는 행동을 뒤집는다.** 무게를 매번 올리기, 숨차게 하기, 오래 달리기, 열심히 하기가 오히려 문제거나 필요 없다고 말한다. 직장인 시청자에게는 "덜 해도 된다"는 허락이자 반전이다.
2. **작고 구체적인 숫자로 쉬워 보이게 한다.** 2개면 충분, 10개 대신 6개, 24kg 1년.
3. **정답을 지시어로 가린다.** "이 운동", "진짜 체력". 무엇에 관한 이야기인지는 분명하다.
4. **본인의 실패담**: 반년 쉬었습니다, 1년간 방치한.
5. **많은 사람이 하는 고민을 그대로 묻는다**: 근력과 유산소 따로?, 숨이 턱까지 차야?

하위 공통점:
- 사무 환경·장비·특정 운동 기술처럼 대상이 좁다(모니터, 의자, 케틀벨 클린 손목).
- "~하는 이유", "~하는 법"으로 설명만 예고하고 반전이 없다.
- 번호가 붙은 시리즈물(다치는 이유2, 3, 클린 1~4단계)이다.
- "이유"로 끝나도 앞부분이 역설이면 상위에 있다("열심히 운동할수록 망하는 이유"). 문장 끝 모양보다 앞부분 내용이 중요하다.

### 앱이 만든 후킹 문구의 성적(2026-09~10)
"체력 키우려면 오래 달리기가 최고 아닌가요?" 203/일, "근력과 유산소 꼭 따로 해야 할까요?" 273/일처럼 통념을 묻는 문구는 중상위였다. "의자에서 일어날 때 왜 손부터 짚게 될까요?", "10회 가능한 무게인데 왜 3~6회 해야할까?"처럼 원리를 묻는 교과서형 질문은 하위권(1.1~2.3천 회)이었다.

### 최근 1년 하위
뇌도 근육처럼 훈련해야 하는 이유(189), 90%는 평생 모르고 사는 가장 놀라운 근육(184), 운동중 귓구멍 막히면 벌어지는 무시무시한 일(149), 초보자 헬스장 가서 딱 '이 5가지'만 하세요(135), 걷기는 '운동'이 아닙니다(110), 체지방 타는 '순서'를 앞당기는 놀라운 비밀(101), 코로 숨쉬면 벌어지는 믿기 힘든 일(96).

관찰:
1. **상위 대부분은 상단 고정 문구가 없다.** 첫 화면을 세로 전체 동작 장면으로 채우고, 첫 발언 자막이 상황을 연다("헬스장에서", "아무리 스트레칭해도", "그냥 매달리지 말고", "넓고 큰 가슴을 만들고 싶다면", "덤벨 하나만 있으면"). 궁금증 문장은 제목이 맡는다.
2. 화면에 큰 글씨를 쓸 때는 시청자에게 직접 말을 거는 문장이다("운동할 때 이거 왜 함?", "한쪽 발이 이렇다면 그냥 지나치지 마세요"). 그리고 같은 장면에 그 대상(코 테이프, 발)이 크게 보인다.
3. 제목 패턴: "~안 크는 사람들 공통점"(외형 결점 + 정체성), "대부분 ~ 몰라요"(나도 해당될까), "'이 운동'하는 사람.. 찐"(정답 가리기 + 정체성), "X 대신 이걸 하세요", "미친/S+/1황/끝판왕/100점"처럼 등급을 매기는 말.
4. 상위 주제는 가슴·등·어깨·허벅지·체형처럼 눈에 보이는 몸 변화다. 하위는 뇌, 귀, 걷기, 체지방 순서처럼 추상적이거나 화면으로 보여주기 어려운 주제다.
5. "놀라운", "무시무시한", "믿기 힘든"처럼 꾸밈말만 강한 문구는 하위권이었다.

## 후킹 v6에 반영할 기준
1. **통념 뒤집기를 1순위 각도로 쓴다.** 시청자가 지금 열심히 하는 행동이 오히려 손해이거나 필요 없다는 반전을 영상 근거에서 찾는다.
2. **작고 구체적인 숫자, 대비되는 숫자**를 쓴다(2개면 충분, 10개 대신 6개). 영상에 있는 숫자만 쓴다.
3. **정답은 가리고 대상은 밝힌다.** "이 운동", "이것"을 쓰되 무엇에 관한 이야기인지는 문구에서 보여야 한다.
4. **정체성·공통점 프레임**: "~하는 사람들의 공통점", "~라면 그냥 지나치지 마세요".
5. **실패담·고백**은 영상에 실제 경험담이 있을 때만 쓴다.
6. **짧게 쓴다.** 상위 문구는 대부분 두 줄, 12~18자 안팎이다. 지금의 15~20자 제한은 문제가 아니다(앞서 제안한 글자 수 완화는 철회).
7. 피할 것: 좁은 대상(특정 장비·사무 환경), 원리만 묻는 교과서형 질문, 시리즈 번호, 꾸밈말만 센 표현, "~하는 법/이유"로 설명만 예고하는 문장.
8. 문구 밖의 요인: 두 채널 모두 높은 조회수 쇼츠는 세로 전체 화면 동작 장면이었다. 롱폼을 레터박스로 자른 형식은 문구와 별개로 상한이 낮아 보인다. 앱의 구도·크롭 기능에서 따로 검토할 과제다.
