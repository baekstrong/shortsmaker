# 0616 영상 쇼츠 5개 후킹 문구 개선안

2026-09-21 사용자 요청에 따른 검토용 문구. 실제 각 구간 전사와 현재 문구를 확인했다. 최초 보고 시 앱 문구는 변경하지 않았으나, 후속 사용자 지적에 따라 아래 추천5개를 앱의 최종 문구에 저장했다. 문구가 바뀌어 확정 상태는 검토 대기로 돌렸다. 기존 AI 후보 목록은 이전 생성 결과이며, 재생성 시 새 기준을 사용한다. 성과 검증 전의 편집 제안이다.

기준: 문구만 읽어도 대상과 상황을 이해할 수 있어야 한다. 이해한 다음 이유가 궁금해야 한다. 영상이 실제로 답하는 질문이어야 하며 결과를 보장하거나 모든 운동에 일반화하지 않는다. 같은 영상의 쇼츠끼리도 관점을 구분한다.

## 1. 힘이 세진다는 것의 의미
- 기존: 힘이 세진다는 건 / 같은 무게를 더 쉽게 드는 것
- 추천: **근육만 키우면 / 힘도 세질까요?**
- 대안: **같은 무게가 가벼워진 이유 / 근육이 커져서만은 아닙니다**
- 이유: 정의를 전달하기보다 근육 크기와 힘을 동일시하는 생각에 질문을 건다. 첫 발언도 힘이 강해지는 의미를 묻고 있어 연결된다.
- 구간 근거: 근육 성장뿐 아니라 동작 연습을 통해 같은 무게를 더 효율적으로 드는 변화를 설명한다. 근육 성장의 기여를 부정하지 않도록 한다.

## 2. 자세와 반복 횟수
- 기존: 10회 할 수 있어도 / 5회에서 멈추는 이유
- 추천: **10개 들 수 있는데 / 왜 5개만 하라는 걸까요?**
- 대안: **자세가 무너져도 / 한 개 더 해야 할까요?**
- 이유: 기존 후보의 장점인 구체적인 숫자와 예상 밖 선택을 유지하고, 시청자의 반문처럼 다듬는다. 문구 자체에 동작을 드러내는 ‘들 수’를 넣는다.
- 구간 근거: 10회 가능한 무게라도 7회부터 자세가 흔들리면 본인은 5회에서 멈추겠다는 예시가 있다. 모든 사람에게 일률적으로 절반만 하라는 규칙으로 표현하지 않는다.

## 3. 피로와 세트 사이 회복
- 기존: 끝까지 밀어붙이면 / 체력 안 늘어나는 이유
- 추천: **지칠 때까지 안 하면 / 운동한 의미가 없을까요?**
- 대안: **첫 세트는 8개, 다음은 4개 / 처음부터 너무 무리했나요?**
- 이유: 영상 속 실제 반론을 가져와 열심히 운동하는 사람이 느끼는 찜찜함을 건드린다. ‘체력이 안 늘어난다’는 광범위한 단정을 제거한다.
- 구간 근거: 초반에 ‘지칠 때까지 안 하면 무슨 운동인가’라는 반론을 직접 제시한 뒤, 후반 세트의 반복 감소와 충분한 휴식을 설명한다. 모든 운동 목적에서 피로를 피해야 한다고 확대하지 않는다.

## 4. 운동 빈도와 한 번의 운동량
- 기존: 운동할 때마다 녹초라면 / 자주 할 수 있게 낮춰보세요
- 추천: **운동을 자주 하면 / 회복이 안 되는 거 아닌가요?**
- 대안: **한 번 운동하면 며칠 쉬어야 한다면 / 운동량부터 돌아보세요**
- 이유: 기존 문구가 바로 제공하던 해결책 대신, 자주 운동하라는 말에 생기는 구체적인 의문을 제시한다. 3번의 세트 안 피로와 달리 며칠 단위 빈도에 초점을 둔다.
- 구간 근거: 영상이 해당 반론을 직접 다루며 한 번의 운동량과 강도를 조절하는 조건을 설명한다. 이 조건 없이 매일 운동해도 회복 문제가 없다고 단정하지 않는다.

## 5. 적은 운동량의 프로그램
- 기존: 10회 할 수 있는데 왜 5회만? / 첫 기준은 자세입니다
- 추천: **운동 두 가지, 5회씩 2세트 / 이걸로 충분할까요?**
- 대안: **운동 두 가지만 하는 / 근력 프로그램이 있다고요?**
- 이유: 2번과 중복되던 반복 횟수·자세에서 벗어나 프로그램 전체의 적은 분량을 소재로 쓴다. 구체적인 구성으로 ‘이 정도로 되나?’라는 의문을 만든다.
- 구간 근거: Power To The People의 두 종목·5회 2세트·주3~5일 구성과 이유가 나온다. 영상 앞부분은 3원칙 복습이라 프로그램 소개까지 도입 시간이 있으며, 문구만 바꾸어 이 간격까지 해결되지는 않는다. 도입 편집은 별도 제안이며 이번 작업에서는 하지 않았다.

## 추천 조합
1. 근육만 키우면 / 힘도 세질까요?
2. 10개 들 수 있는데 / 왜 5개만 하라는 걸까요?
3. 지칠 때까지 안 하면 / 운동한 의미가 없을까요?
4. 운동을 자주 하면 / 회복이 안 되는 거 아닌가요?
5. 운동 두 가지, 5회씩 2세트 / 이걸로 충분할까요?

이번 구간들은 시청자의 반론을 직접 다루어 질문형을 추천했지만, 질문형 자체를 생성의 고정 규칙으로 삼지는 않는다. ‘만으로 이해 가능 → 궁금한 이유 존재 → 구간 안에서 답함’을 고정 기준으로 삼는다.
