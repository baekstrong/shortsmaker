# 샘플 영상 검토 상태

출처: 2026-09-09 사용자 지정 로컬 경로와 첨부 이미지.

## 검토 상태
- 두 원본 및 쇼츠 영상 28개는 macOS dataless 플래그가 있어 영상 내용이 로컬에 없는 상태다. FileManager.startDownloadingUbiquitousItem 다운로드 요청은 성공했으나 로컬 영상 내용 확보는 확인되지 않았다.
- ffprobe 및 프레임 추출은 완료하지 못했다. 영상의 길이·코덱·주제 경계·실제 크롭 수치는 아직 측정하지 않았다.
- 원데이 수업 이론: 원본 1개, 쇼츠 폴더 영상 16개(번호 파일 8개, 제목 파일 8개), 텍스트 8개.
- 운동 밀당: 원본 1개, 쇼츠 폴더 영상 10개(번호 파일 5개, 제목 파일 5개).
- 번호 파일은 중간 분할본, 제목 파일은 완성본일 가능성이 있으나 영상 비교 전이므로 확정하지 않는다.

## 이미지에서 확인한 화면
- 검은 세로 캔버스, 상단 중앙 정렬 2줄 후킹 문구(첫 줄 노랑, 둘째 줄 흰색), 굵은 글씨.
- 중앙에 좌우를 자른 영상, 영상 내부 하단에 기존 흰색 자막과 검은 외곽선, 영상 아래 검은 여백.
- 이미지 문구: 수백 명 가르치고 알게 된 / 단 하나의 차이.
- 이미지로 폰트 이름이나 실제 렌더 좌표를 확정하지 않는다.

## 다음 검토
- Finder에서 두 폴더를 다운로드한 뒤 ffprobe와 대표 프레임 비교를 다시 실행한다.
- 원본과 번호 분할본, 제목 완성본의 길이·오디오를 대조해 연속 추출인지 내부 축약이 있는지 확인한다.
- 후킹 생성은 과거 문구 모방을 전제하지 않는다. 샘플은 화면 배치와 결과물 검증에 사용한다.
